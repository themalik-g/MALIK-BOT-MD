### 🖥️ VPS / Dedicated Server

> **Recommended for 24/7 stable hosting**

#### Step 1: Update & Install Dependencies
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git nodejs npm ffmpeg imagemagick webp
```

#### Step 2: Clone Repository
```bash
git clone https://github.com/themalik-g/MALIK-BOT-MD.git
cd MALIK-BOT-MD
```

#### Step 3: Install Packages
```bash
npm install
```

#### Step 4: Configure Settings
Edit `settings.js` or create a `config.env`:
```javascript
module.exports = {
    ownerNumber: "911234567890",
    botName: "𝙈𝘼𝙇𝙄𝙆 𝙈𝘿",
    prefix: ".",
    // ... other settings
}
```

#### Step 5: Start the Bot
```bash
node index.js
```

#### 🔄 Run with PM2 (For 24/7)
```bash
npm install -g pm2
pm2 start index.js --name "malik-md"
pm2 save
pm2 startup
```

## 🛠️ Troubleshooting

<details>
<summary><b>❌ Error: "Session folder deleted. Please re-authenticate."</b></summary>

This happens when you get logged out (status 401).
- Delete the `session/` folder manually
- Re-scan QR or enter pairing code again
- Do NOT use the same session on multiple devices simultaneously

</details>

<details>
<summary><b>❌ Error: "Cannot find module '@whiskeysockets/baileys'"</b></summary>

Run:
```bash
rm -rf node_modules package-lock.json
npm install
```

</details>

<details>
<summary><b>❌ Bot connects but doesn't respond to commands</b></summary>

- Check if `prefix` is set correctly in `settings.js`
- Make sure `public: true` is set (or add your number to owner list)
- Check logs for errors in `main.js`

</details>

<details>
<summary><b>❌ "RAM too high" or process killed</b></summary>

- Enable swap memory on your VPS
- Use the built-in GC: run with `node --expose-gc index.js`
- Reduce `syncFullHistory: false` (already set by default)

</details>

<details>
<summary><b>❌ QR Code not showing / Pairing code not working</b></summary>

- Make sure your terminal supports interactive input
- For non-interactive panels, set `ownerNumber` in `settings.js` before starting
- Use pairing code for headless/VPS deployment

</details>
